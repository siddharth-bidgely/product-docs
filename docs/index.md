# DETO - Delivery Tools

Welcome to the documentation for **DETO (Delivery Tools)**, Bidgely's self-serve platform for energy utilities.

DETO empowers utility companies to manage customer onboarding, configure products, author content, and orchestrate deployments — all from a single web-based platform.

## What is DETO?

DETO is a suite of tools built for Product Managers, Customer Success teams, and Enterprise Administrators. It removes the need for manual handoffs between teams by providing self-serve capabilities for:

- **Project Management** — Create and configure utility pilot projects
- **Content Authoring** — Manage recommendations, surveys, media, and templates
- **Product Configuration** — Customize features, config registries, and data scenarios
- **Visual Editing** — Design customer experiences with a drag-and-drop editor
- **Workflow Automation** — Build approval and review workflows visually
