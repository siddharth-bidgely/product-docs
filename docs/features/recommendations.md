## Overview  
The **Recommendations** area of the DETO dashboard lets utilities create, edit, review, and publish personalized energy‑saving suggestions.  It is a self‑serve content management system that keeps all recommendation data in one place, independent of code deployments.  Designers, product managers, and customer‑success teams can author new recommendations, set targeting rules, and preview how the content will appear in the customer experience before it goes live.  The workflow is fully audit‑traced, versioned, and protected by role‑based access control, so only authorized users can publish or delete content.

## Key Capabilities  
- **Create** new recommendations from a wizard or inline form.  
- **Edit** existing recommendations, including title, description, media, and targeting rules.  
- **Publish** or **Unpublish** recommendations once they pass review.  
- **Bulk actions** – publish, delete, or submit multiple items at once.  
- **Filter** the list by status, locale, or category.  
- **Live preview** – see the recommendation as it will appear in the CX product.  
- **Comments & feedback** – threaded discussions on each recommendation.  
- **Score thresholds** – configure ranking thresholds for recommendation visibility.  
- **Upload** recommendations in bulk via Excel.  
- **Clone pilot** – duplicate a pilot project with its recommendations.

## User Guide  

### Create a Recommendation  
1. From the CMS area, open **Recommendations**.  
2. Click **Create New Recommendation**.  
3. In the wizard, enter the **Title**, **Description**, and optional **CTA**.  
4. Add media (image or video) and set the target **Locale**.  
5. Click **Save Draft** to keep a working copy or **Submit for Review** to move it to the review queue.  
   ![Short description](../assets/images/815431723-Screenshot-202025-11-11-20at-2011.32.07-E2-80-AFAM.png)  

### Edit a Recommendation  
1. Open **Recommendations** and locate the item you want to change.  
2. Click the **Edit** button next to the recommendation.  
3. Modify any field – title, description, media, or targeting rules.  
4. Click **Save Updates** to keep the changes as a new draft or **Submit for Review** to advance the status.  
   ![Short description](../assets/images/815431723-Screenshot-202025-02-22-20at-2010.51.10-E2-80-AFPM.png)  

### Publish a Recommendation  
1. In the **Recommendations** list, find the recommendation whose status is **READY_TO_PUBLISH**.  
2. Click **Publish**.  
3. Confirm the action in the dialog that appears.  
4. The recommendation becomes **Published** and is live in the CX product.  
   ![Short description](../assets/images/815431723-Mermaid-20Chart-20-20Create-20complex-20visual-20diagrams-20with-20text.-2025-10.png)  

### Bulk Operations  
1. Select multiple rows using the checkboxes in the table header.  
2. Click **Bulk Actions** and choose **Publish**, **Unpublish**, or **Delete**.  
3. Confirm the bulk action in the dialog that appears.  

### View Comments  
1. Open a recommendation and click the **Comments** icon.  
2. A side panel shows the threaded discussion.  
3. Add a new comment, reply, or resolve existing threads.  

## Configuration Options  
- **Locale Settings** – admins can add or remove supported locales for a pilot.  
- **Score Thresholds** – set minimum and maximum scores for each recommendation category.  
- **Role Permissions** – administrators control which roles can create, edit, publish, or delete recommendations.  
- **Audit Trail** – view version history and status changes for each recommendation.
