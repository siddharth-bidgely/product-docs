## Overview

The DETO Project Management area lets you create, view, and update projects that run on the platform.  
When you start a new project, the system automatically provisions a cloud environment, sets up ingestion pipelines, and configures the customer‑facing web experience.  
Project managers, data analysts, and product owners use this area to keep projects on schedule, review environment status, and fine‑tune analytics and alerts.

---

## Key Capabilities

- **Create a new project** with a single click and automated environment provisioning.  
- **Open an existing project** from the dashboard to see its details.  
- **View and refresh project environments** to monitor deployment progress.  
- **Edit configuration fields** (e.g., ingestion, pipeline, application scope).  
- **Push configuration changes** to the live project with a single approval step.  
- **Configure pipeline components** (core processing, custom models, etc.).  
- **Set application scope** by toggling modules for each fuel type.  
- **Save and apply changes** across the project.  
- **Navigate back** to the dashboard or other sections with ease.  
- **Access project‑specific analytics** and recommendations from the same page.

## User Guide

### 1. Create a New Project

1. Open the **Projects** dashboard from the main menu.  
   ![Projects Dashboard](../assets/images/847642630-Screenshot-202025-08-27-20at-205.13.53-E2-80-AFPM.png)  
2. Click the **Create Project** button.  
   ![Create Project Button](../assets/images/847642630-Screenshot-202025-08-27-20at-205.13.16-E2-80-AFPM.png)  
3. In the **Project Creation** form, enter the project name, description, and pick a region.  
   ![Project Creation Form](../assets/images/847642630-Screenshot-202025-08-27-20at-205.12.58-E2-80-AFPM.png)  
4. Select the utility and environment type, then press **Create**.  
   ![Create Confirmation](../assets/images/847642630-Screenshot-202025-08-27-20at-205.31.50-E2-80-AFPM.png)  
5. Wait while the system provisions the environment; a progress bar will show the status.  
6. When the project appears in the dashboard, a confirmation message will appear.  

---

### 2. View Project Details

1. From the **Projects** dashboard, click **Open Project** on the desired project.  
   ![Open Project](../assets/images/853245955-Screenshot-202025-08-28-20at-203.14.27-E2-80-AFPM.png)  
2. The **Project Details** page opens, displaying core attributes such as Project ID, Name, Country, and more.  
   ![Core Attributes](../assets/images/853245955-Screenshot-202025-08-28-20at-203.18.15-E2-80-AFPM.png)  
3. Scroll to the **Project Environments** section to see each environment and its current status.  
   ![Environment List](../assets/images/853245955-Screenshot-202025-08-28-20at-203.27.41-E2-80-AFPM.png)  
4. Click an environment to view its details or status.  
5. Use the **Refresh** button to update the status if needed.  
6. Return to the dashboard by clicking the **Back** button.
