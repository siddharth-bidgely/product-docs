## Overview
Survey Builder empowers delivery teams and system administrators to dynamically build, manage, and deploy user surveys natively from the CMS dashboard. Surveys act as powerful insight-gathering engines (e.g., Home Energy assessments, feedback forms) without requiring hard-coded engineering logic.

## Key Capabilities
- **Template Authoring:** Design linear or branched survey layouts (Survey Templates) mapping directly to customer segments.
- **Dynamic Question Banks:** Configure discrete, categorical, or open-ended `survey-questions`.
- **Validation Rules:** Inject rules natively into the forms (e.g. required fields, integer matching).

## User Guide

### 1. Constructing a Question Bank
1. Open **Survey Builder** from the CMS menu.
2. Under the Questions tab, enter the prompt text, data type (Number, Text, Select), and provide predefined answer ranges.
3. Save the questions into logical categories (e.g., Heating, Appliances).

### 2. Building the Template
1. Create a **New Survey Template**.
2. From the right-bar module picker, sequentially drag individual Questions onto the canvas.
3. Define page breaks or next-step transitions to guide users seamlessly.
