# Platform Overview

DETO (Delivery Tools) is Bidgely's self-serve platform for energy utility project delivery. It provides a centralized web-based interface for managing all aspects of customer onboarding and product configuration.

## Who Uses DETO?

| Role | Primary Use Cases |
|------|-------------------|
| **Product Managers** | Configure features, manage content, review recommendations |
| **Customer Success** | Set up new utility projects, manage pilots, monitor deployment |
| **Enterprise Admins** | Manage environments, control access, configure integrations |
| **Content Creators** | Author recommendations, build surveys, design CX templates |

## Key Capabilities

### Content Management
Create, review, and publish energy recommendations with support for multiple locales, bulk operations, and draft/publish workflows.

### Project Setup
One-click project creation with template-based configuration. Manage appliance profiles, home profiles, and recommendation scores per utility.

### Product Configuration
Centralized config registry for managing application settings. Compare and sync configurations across environments.

### Visual Experience Design
Drag-and-drop editor for designing customer-facing digital experiences with real-time preview.

### Survey Management
Build customer surveys with branching logic, multi-level questions, and template management.

### Workflow Automation
Design approval workflows visually using a node-based graph editor.
