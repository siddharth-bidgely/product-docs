# Glossary

| Term | Definition |
|------|-----------|
| **DETO** | Delivery Tools — Bidgely's self-serve platform for energy utility project delivery |
| **Pilot** | A utility project configuration, also called a "project" |
| **Utility** | An energy utility company that is a Bidgely customer |
| **CMS** | Content Management System — the backend service managing all content |
| **Recommendation** | An energy-saving tip or action item presented to utility customers |
| **CX** | Customer Experience — the end-user facing product |
| **DCX** | Digital Customer Experience — digital channel configurations |
| **Config Registry** | Centralized store for application configuration key-value pairs |
| **Draft** | A working version of content that has not been published |
| **Published** | The live version of content visible to external consumers |
| **Data Scenario** | A test/demo data configuration for a specific product type and fuel type |
| **Feature Workflow** | A visual graph defining system node relationships and approval processes |
| **System Node** | A component in a workflow graph (storage, API, daemon, pipeline, module, product) |
